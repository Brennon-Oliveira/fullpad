01 · formatos

Uma visão própria para cada formato

O fullpad olha a extensão e põe, ao lado do texto, a visão que faz sentido para aquele arquivo. Você continua no mesmo editor, com as mesmas abas e os mesmos atalhos.

02 · markdown

O formato que recebeu mais cuidado

Quem escreve em Markdown vive alternando entre o código e o resultado. No fullpad você troca de visão com Ctrl+E, edita direto no preview e pula de seção pelo sumário lateral.

| a | b |

Tabelas em grade

Edite a tabela como numa planilha, sem alinhar barra vertical na mão.

$e^{i\pi}$

Equações KaTeX

graph LR

Diagramas Mermaid

.html .pdf

Exportação

Gere HTML ou PDF, ou copie como HTML para colar formatado num e-mail.

03 · arquivos grandes

Um CSV de 14,6 GB abre em menos de meio segundo

Acima de 20 MB, o fullpad lê o arquivo por partes, conforme você navega, por isso o tamanho quase não pesa na abertura. Dá para pular para uma linha, buscar direto no disco e editar com desfazer, sem esperar o arquivo inteiro subir para a memória.

04 · confiança

Fechou sem querer? Ctrl+Shift+T traz de volta

Cada aba guarda o texto enquanto você digita. Fechar a aba ou o app não descarta nada, e o histórico de abas, no Ctrl+Shift+H, mostra tudo o que passou por ali.

tmp + rename

Escrita atômica

O arquivo é gravado por inteiro ou continua como estava. Uma queda de energia no meio do salvamento não deixa meio texto no disco.

utf-8 · latin-1

Codificação preservada

Abriu em Latin-1, salva em Latin-1. Os acentos daquele CSV antigo continuam no lugar.

crlf · lf

Quebras de linha mantidas

CRLF continua CRLF e LF continua LF, então o diff do Git mostra só o que você mudou.

F5

Aviso de mudança externa

Se outro programa mexer no arquivo aberto, o fullpad avisa. F5 recarrega a versão do disco.

05 · teclado

Tudo o que está nos menus cabe no Ctrl+P

A paleta de comandos lista cada item dos menus com o atalho ao lado e entende busca aproximada: "dvd" acha "Dividir painel". Experimente aqui.

    Nenhum comando com esse nome. Tente "salvar" ou "painel".

    06 · bancada

    $ cargo tauri build

    Como foi feito

    Rust no núcleo, Tauri 2 para a janela e CodeMirror 6 no editor. O código é aberto sob licença MIT, e qualquer pessoa pode compilar com Rust, Node e pnpm.

    o que ainda não funciona

    • Não há versão para macOS.
    • O instalador do Windows não tem certificado da Microsoft, então o SmartScreen avisa na primeira execução. As atualizações automáticas são assinadas pelo projeto.
    • Arquivos .tex mostram as equações, mas o fullpad não compila o documento.
    • PDF e EPUB são só leitura: dá para buscar e copiar, nada é gravado no arquivo.
