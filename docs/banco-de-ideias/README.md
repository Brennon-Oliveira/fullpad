# Banco de ideias

Features pensadas para o Fullpad e ainda não planejadas em fases no [PLANO](../PLANO.md). Cada ideia é um arquivo com cabeçalho:

```yaml
---
titulo: <nome da ideia>
feita: não | sim
versao: <versão em que saiu; "—" enquanto não foi feita>
---
```

Ao implementar uma ideia, troque `feita` para `sim`, preencha `versao` e atualize a tabela abaixo.

A lista ordenada por importância, com os motivos, está em [prioridades.md](prioridades.md).
