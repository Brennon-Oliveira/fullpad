# Banco de ideias

Features pensadas para o Fullpad e ainda não planejadas em fases no [PLANO](../PLANO.md). Cada ideia é um arquivo com cabeçalho:

```yaml
---
titulo: <nome da ideia>
feita: não | sim
versao: <versão em que saiu; "—" enquanto não foi feita>
---
```

Ao implementar uma ideia, troque `feita` para `sim`, preencha `versao` e atualize a tabela abaixo.

| Ideia | Feita | Versão |
|---|---|---|
| [Referência com volta (link da nota para o ponto do PDF/EPUB)](referencia-com-volta.md) | não | — |
| [Nota ao lado do leitor (e "nota do livro")](nota-ao-lado-do-leitor.md) | não | — |
| [Busca em todas as abas + refação visual da busca](busca-global.md) | sim | próxima (a definir) |
| [Paleta de comandos](paleta-de-comandos.md) | não | — |
| [Sumário lateral](sumario-lateral.md) | não | — |
| [YAML e TOML](yaml-toml.md) | sim | próxima (a definir) |
